# Foundations

A screen direction only makes sense at the observer’s current point. The minimum local data for a Riemannian observation model is a manifold M, point p∈M, tangent vector v∈TₚM, metric g, and usually connection ∇. The metric measures angles and speeds. The connection differentiates values in changing tangent spaces.
