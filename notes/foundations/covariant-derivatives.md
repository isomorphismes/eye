# Covariant differentiation

For V=Vᵏ∂ₖ, (∇ᵢV)ᵏ=∂ᵢVᵏ+ΓᵏᵢⱼVʲ. For α=αⱼdxʲ, (∇ᵢα)ⱼ=∂ᵢαⱼ−Γᵏᵢⱼαₖ. Each upper index receives +Γ and each lower index −Γ.

Along γ(t), a vector V(t)∈T_{γ(t)}M has

DVᵏ/dt=dVᵏ/dt+Γᵏᵢⱼ(γ)γ̇ⁱVʲ.

This lives in the current tangent space, unlike a plain component derivative. It is the invariant for ray velocity and observer-frame evolution.

A connection is linear in direction and obeys a Leibniz rule. Those rules, not one coordinate formula, are the structural interface a future typed representation should expose.
