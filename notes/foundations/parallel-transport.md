# Parallel transport and holonomy

V along γ is parallel when DV/dt=0. Parallel transport P_γ maps T_{γ(0)}M to T_{γ(1)}M. For a metric connection it preserves inner products, so an observer frame stays orthonormal.

Transport depends on the path in curved geometry. Carry a vector around a sphere loop and it returns rotated relative to the initial frame. That holonomy shows why tangent spaces lack a hidden global identification.

For eye motion, separate:
- **parallel frame:** D eᵢ/dt=0;
- **body-controlled frame:** add a chosen local rotation to transported eᵢ.

When a quotient representative is replaced by A(p), its full frame must become dA(eᵢ). Moving only the point makes the next viewing directions wrong.
