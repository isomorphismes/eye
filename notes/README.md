# Notes map

The first corpus contains source records, foundational derivations, observation notes, eight geometry studies, code surveys, worked calculations, and architecture notes.

Unless a note says otherwise, coordinates are x¹,…,xⁿ, the metric is gᵢⱼ dxⁱ dxʲ, and ∇_{∂ᵢ}∂ⱼ = Γᵏᵢⱼ∂ₖ. Curvature uses R(X,Y)Z = ∇ₓ∇ᵧZ − ∇ᵧ∇ₓZ − ∇_[X,Y]Z. Changing convention changes signs or index order, not the geometry.

- [Sources](sources/README.md): evidence and licenses.
- [Foundations](foundations/README.md): objects Eye will name before computing.
- [Seeing](seeing/README.md): observation-specific questions.
- [Thurston geometries](thurston/README.md): one study per geometry.
- [Code survey](code-survey/README.md): audited capabilities.
- [Worked examples](worked/README.md): calculations with invariants.
- [Architecture](architecture/README.md): semantic boundary, no backend decision.
