# Emmy and executable FDG

**Status:** source-inspected at repository README and public documentation.

Emmy implements scmutils ideas in Clojure and ClojureScript. The inspected README promises symbolic computation, automatic/numerical/symbolic differentiation, integration, optimization, differential geometry, and mechanics. The public connection and covariant namespaces make it a strong oracle for local coordinate formulas.

Suitable Eye uses: derive Christoffel coefficients from gᵢⱼ; check a covariant derivative expansion; simplify geodesic equations; compare exact and symbolic invariants. It can also document a calculation in executable form later.

Not suitable by itself: defining the whole quotient scene, identifying all visible lifts, picking a GPU representation, or certifying error through cut loci. Its host language and generic arithmetic are not a commitment for Eye.
