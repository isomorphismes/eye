The connection is built as a Lean term dependent on the smooth manifold, bundle, metric and regularity assumptions.

This is **formal mathematics**: proofs of uniqueness, construction, compatibility and torsion conditions can be checked by Lean's kernel when built against their dependencies. It is not proof that floating-point coordinate integration is accurate, nor that all eight geometries have runtime shaders. A point-indexed tangent-space type such as **TangentSpace I x** expresses exactly the base-point dependence Eye needs. The Levi-Civita construction is noncomputable in the indicated formal context and not an exported GPU function.

**Testing:** theorem definitions/proofs live with source files and are checked under the Mathlib Lean/Lake build; no separate computational accuracy test has been executed in this task. **Dependencies:** Lean4, Mathlib modules, bundled ecosystem and prescribed toolchain. **Limitations:** smoothness and chart-domain hypotheses require care; proof statements need actual imports and compiled closure, not name-matching. Exact symbols listed above came from inspected generated documentation, not an independent rebuild.

**Proposed Eye reuse:** use dependent tangent fibers, metric compatibility and transport laws as specification patterns; reference proofs by qualified names. Leave numerical solvers and quotient events to another layer. [Related fork](differential-geometry-lean-fork.md).
