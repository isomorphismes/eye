# Walnut & Burgundy differential-geometry: substantial formal corpus already exists

**Status: inspected fork [fd2f07f](https://github.com/walnut-burgundy/differential-geometry/tree/fd2f07fba4c6c102ba626c59153ad98da8f0d442) directories and selected Lean declarations. License Apache-2.0. No Lake compilation run.**

This source is not a bare vector-bundle tutorial. [DifferentialGeometry/Geometry/Thurston/Models.lean](https://github.com/walnut-burgundy/differential-geometry/blob/fd2f07fba4c6c102ba626c59153ad98da8f0d442/DifferentialGeometry/Geometry/Thurston/Models.lean) defines the eight constructors of **ThurstonModel** and proves **ThurstonModel.card** equals 8 by decide. It also defines **CoordinateModel**, **coordinateCoframe**, **coordinateInner**, and lemmas **coordinateCoframe_injective** and **coordinateInner_pos**. That is more directly useful to Eye's geometry inventory than the generic Mathlib connection alone.

[ElementaryModels.lean](https://github.com/walnut-burgundy/differential-geometry/blob/fd2f07fba4c6c102ba626c59153ad98da8f0d442/DifferentialGeometry/Geometry/Thurston/ElementaryModels.lean) declares spherical, Euclidean, and product metric/complete-model results. The [Thurston directory](https://github.com/walnut-burgundy/differential-geometry/tree/fd2f07fba4c6c102ba626c59153ad98da8f0d442/DifferentialGeometry/Geometry/Thurston) includes atlas, discrete-deck, model and equivariant metric studies. Do **not** infer that every constructor already has a proven concrete complete homogeneous metric: inspect the specific theorem and hypotheses.

[Connection/OrthonormalFrame.lean](https://github.com/walnut-burgundy/differential-geometry/blob/fd2f07fba4c6c102ba626c59153ad98da8f0d442/DifferentialGeometry/Geometry/Connection/OrthonormalFrame.lean) defines **coframeConnectionForm** and **orthonormalFrameConnectionForm**, with metric-compatible skew-adjointness results. [Connection/ParallelTransport](https://github.com/walnut-burgundy/differential-geometry/tree/fd2f07fba4c6c102ba626c59153ad98da8f0d442/DifferentialGeometry/Geometry/Connection/ParallelTransport) has modules for frames, horizontal lifts, and pullbacks. [Geometry/Geodesic](https://github.com/walnut-burgundy/differential-geometry/tree/fd2f07fba4c6c102ba626c59153ad98da8f0d442/DifferentialGeometry/Geometry/Geodesic) includes local equations, flows and rays.

**Types/dependencies:** Lean4 dependent types, Mathlib, [lakefile.toml](https://github.com/walnut-burgundy/differential-geometry/blob/fd2f07fba4c6c102ba626c59153ad98da8f0d442/lakefile.toml), [lean-toolchain](https://github.com/walnut-burgundy/differential-geometry/blob/fd2f07fba4c6c102ba626c59153ad98da8f0d442/lean-toolchain). **Formal test criterion:** compile the pinned import closure and inspect whether targeted theorems have unwanted assumptions or admits; neither was done here. **Limit:** formal definitions/proofs do not themselves implement floating-point shader flow, quotient marching, or observable image synthesis.

**Eye consequence:** reference specific proofs and names, do not rebuild the same bundle and connection formalism in a new language as part of this corpus.
