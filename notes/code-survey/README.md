# Code survey

The purpose of this directory is refusal to conflate unlike tools.

| System | Domain | What Eye may learn | What it does not supply |
| --- | --- | --- | --- |
| Mathlib | formal proof | point-indexed tangent and connection semantics | numerical ray propagation |
| Emmy | symbolic and numerical algebra | coordinate derivations | scene traversal |
| geometry-central | 2D surface meshes | intrinsic tracing and transport interfaces | 3D Thurston world |
| DiGeo | differentiable triangle meshes | batched mesh kernels | quotient visibility |
| Manifolds.jl | numerical manifold API | exp/log/transport vocabulary | eight-geometry renderer |
| DEC | cochains on cell complexes | forms and operators | observer frames |
| Egison | language and tensor notation | expressive index patterns | geometry engine |
| non-euclidean_VR | real-time WebGL | closest full reference | no reason to adopt its renderer |
