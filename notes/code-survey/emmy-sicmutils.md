[SICMUtils source](https://github.com/sicmutils/sicmutils/tree/e325fd46fcca0e1577cc9b7f7d680a721144f27d/src/sicmutils/calculus) has corresponding calculus modules; the systems share mathematical heritage and should not be counted as independently verified results merely because both implement similarly named formulas.

**Types:** Clojure(Script) generic symbolic expressions, structured coordinate/basis and connection objects, rather than static dependent fibers. **Capabilities:** symbolic Christoffels, differential forms, curvature, generic differentiation and numerical tools. **Limitations:** no verified intrinsic scene intersection, all-eight-model visibility, or real-time renderer contract from these modules. **Reuse:** use them as an oracle for local connection and curvature identities after aligning notation and checking actual evaluated outputs.
