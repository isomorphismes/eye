## Status vocabulary

**Inspected:** specified lines/sections or directories actually read. **Metadata-only:** bibliographic page or project listing checked, not its full mathematical content. **Independently derived:** explicit calculation carried out in the notes, with a check condition; this does not certify a numerical test was executed. **Unverified:** design hypothesis or evidence still to collect. In particular, lack of a listed test here means **not inspected**, not **no tests exist**.

## Rights boundary

Cite sources and link to pinned files; write original formulas and explanations. Avoid transplanting GPL shader implementations into independently licensed source. The choice to use any external code must be accompanied by a compatibility review and preserved notices. No third-party code is vendored into Eye by this corpus, and source availability does not imply unrestricted redistribution of books, figures, or PDFs.
