# Reuse and license discipline

**Status:** source-inspected only where top-level material states a license; otherwise open.

This corpus is original exposition. It may cite a paper section, public source path, API identifier, or brief name. It does not mirror PDFs, source trees, figures, or long excerpts.

- Mathlib’s inspected Levi-Civita file states Apache-2.0.
- DiGeo’s inspected README displays BSD-3-Clause.
- DiscreteExteriorCalculus.jl public metadata reports BSD-3-Clause.
- An arXiv submission license does not authorize repackaging its paper figures or text.
- Geometry-central, Emmy, Manifolds.jl, and Egison need an exact upstream license check before code copy.

A future implementation may use ideas, independently derived formulas, or a narrow API design without copying code. Any code copy needs file-level license confirmation and attribution.
