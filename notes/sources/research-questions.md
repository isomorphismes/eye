# Open research questions

**Status:** open questions, not requirements disguised as conclusions.

1. Which closed-form geodesic and parallel-transport functions from the central implementation can be re-expressed in a small typed numeric interface without importing its renderer?
2. Which quotient representations permit robust fundamental-domain crossing on modest mobile hardware?
3. For each geometry, which scene primitives have certified distance underestimators rather than merely plausible chart distances?
4. Where do cut loci or multiple lifts make a single-image cache unsound?
5. Can a formal statement about point-indexed tangent spaces and connection laws be shared with Idriç without turning Eye into a theorem prover?
6. Which parts of non-euclidean_VR are mathematics, which are JavaScript/WebGL adaptation, and which are reusable scene semantics?
7. How should intrinsic 3D visibility be stress-tested separately from an embedded-surface renderer?

A good answer needs a source or a derived calculation. The list is intentionally not a renderer roadmap.
